# База знаний «Мамин помощник»

Это **внутренняя** рабочая база, а не раздел статей на сайте. Родители получают ответ в чате; интерфейс не показывает этот каталог, ссылки на первоисточники или форумные материалы.

## Что уже есть

- `catalog/question-taxonomy.ru.json` — стартовая карта из естественных формулировок родителей. Это не ответы и не медицинские утверждения.
- `catalog/red-flags.ru.json` — события, для которых чат не даёт обычный ответ и предлагает срочно обратиться за помощью.
- `sources/source-registry.json` — внутренний реестр допустимых типов и доменов источников.
- `policies/live-retrieval-policy.md` — правила поиска в интернете, если внутренней базы недостаточно.
- `research/forum-language-observations.md` — только исследование языка вопросов; форумные советы не используются как знания.

## Как из карты вопросов получается безопасный ответ

1. Редактор выбирает вопрос/намерение из каталога.
2. Находит действующий первичный источник в реестре.
3. Создаёт карточку: утверждение, применимые условия, исключения, красные флаги, ссылка на источник, версия и дата проверки.
4. Медицинский редактор утверждает карточку. Только тогда она переходит в `approved` и становится доступной чату.
5. Если карточки нет, она устарела или не подходит к ситуации, чат не импровизирует: объясняет ограничение и предлагает обратиться к подходящему специалисту.

В первой публичной версии родителям нельзя обещать «ответ на всё». Каталог вопросов намеренно шире утверждённых ответов: он показывает, что ещё предстоит закрыть проверенным материалом.

## Статусы карточек

- `candidate` — есть тема/вопрос, клинического текста ещё нет.
- `researching` — найден источник, идёт разбор и проверка актуальности.
- `medical-review` — черновик проверяет медицинский редактор.
- `approved` — можно выдавать в чате с учетом условий карточки.
- `archived` — источник заменён или карточка больше не используется.

## Чего здесь не будет

- ответов с форумов, социальных сетей, маркетплейсов, блогов и рекламных страниц;
- самостоятельных назначений, дозировок, диагнозов, «норм» для всех детей;
- загрузки личных медицинских документов в общий поисковый индекс;
- автоматической публикации материала, который AI нашёл в интернете.
