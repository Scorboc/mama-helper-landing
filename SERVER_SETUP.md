# Подключение серверной части MAMA Helper

Основное приложение находится в app/. Для текущего локального запуска используйте существующий supervisor и настройки из private. Не заменяйте рабочую базу и не создавайте новый APP_DATA_KEY поверх существующих данных.

Перед публичным запуском прочитайте DEPLOYMENT.md, deploy/hybrid/README.md и docs/legal/OWNER_LAUNCH_CHECKLIST.md. Нужны утверждённая площадка, защищённые настройки, резервная копия и проверка восстановления. Адрес API задаётся через публичную конфигурацию сайта; ключи остаются на сервере.

Проверяйте регистрацию, вход, восстановление доступа, изоляцию аккаунтов, дневник, чат, лимиты, срочную помощь, оплату и возврат в предусмотренном режиме. Используйте синтетические данные. Реальные платные тесты требуют согласованного бюджета.

Секреты, профили и переписку не публикуйте. Новый сервер не считается готовым только после сборки интерфейса. Старую рабочую систему сохраняйте до успешной проверки нового размещения и отката.
