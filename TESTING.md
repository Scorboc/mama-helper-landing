# Тестовая версия без API

Главная страница — интерфейс помощника. Компоненты старого лендинга сохранены, но не отображаются.

Работает: готовые сценарии чата, роль родителя, ручной возраст/срок, один пример возрастного события (6 месяцев), скрытие/повтор карточки, ручной тест уведомления, ссылки на источники. Всё состояние только в памяти React; перезагрузка его очищает. Не вводите реальные чувствительные данные.

Не подключено: генеративный AI, авторизация, база данных, фоновые push, платежи, автоматический возраст, полный клинический календарь. Клиническая валидация не проведена. Ключевые слова не обеспечивают надёжный триаж.

## Подключение AI

Точка интеграции: `src/lib/assistant.ts`, `assistant.reply(question, profile): Promise<Reply>`. Заменить адаптер запросом к своему серверу. Ключи только в серверных секретах, не в `VITE_*`, исходниках или GitHub.

Сервер должен проверять авторизацию, лимиты, источники и цитаты; маршрутизировать Lite/Max с безопасной эскалацией; отказываться при недостатке данных. Текущий роутер — только демонстрация. Не отправлять медицинские данные внешним провайдерам до определения согласий и правил обработки.

Фоновые push требуют service worker, подписок Web Push и серверного планировщика с дедупликацией. Текущий Notification API — ручной тест на открытой странице.

## Проверка

`npm ci`, `npm run build`, `npx tsc --noEmit`.

Сценарии: три предложенных вопроса; неизвестный вопрос; кризисная фраза; смена срока/возраста; 6 месяцев → карточка в чате; скрыть/вернуть карточку; отказ разрешения уведомлений; перезагрузка очищает данные. После подключения сервера добавить проверки изоляции аккаунтов и клинические тесты.
