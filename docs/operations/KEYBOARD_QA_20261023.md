# Экранная клавиатура — 23.10.2026

## Область и исправления

Чат, быстрые формы, книга первого года, вопросы врачу, вход и регистрация. Один общий обработчик VisualViewport передаёт высоту/смещение в CSS в том числе для портальных диалогов. Старый обработчик только для RoomSurface удалён. Центрированные DialogContent помечены отдельным data-input-dialog, Popover и Sheet не перемещаются. Диалоги ограничены видимой высотой и прокручиваются внутри. При вводе освобождается место от нижней навигации/декоративных рук; после закрытия всё возвращается. Убраны два вложенных обрезающих контейнера быстрой заметки на время клавиатуры. Прокрутка оставляет до72px для соседней кнопки, сохраняя место самому полю. Поля на мобильной ширине имеют минимум16px, ручное масштабирование не запрещается.

Обработчик не читает значения полей и пароли, не сохраняет ввод, не вызывает backend. Небольшие изменения панели браузера/панорамирование не возвращают пользователя к полю. При масштабировании сохраняется раскладка ввода, а blur снимает keyboard-open даже при увеличенном масштабе.
