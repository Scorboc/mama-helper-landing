## Изменения

- Верхнее меню закреплено; его фактическая высота измеряется ResizeObserver, в том числе при переносе текста на320px. Контент получает соответствующий верхний отступ.
- Нижняя навигация закреплена во всех разделах. Устранено старое hover-правило left:auto, которое сдвигало меню при нажатии. Внизу страниц зарезервировано место для навигации.
- При открытой экранной клавиатуре поле чата закреплено по координатам одной VisualViewport: top=offsetTop+height−измеренная высота composer−8. Не смешивается с100dvh. Нижняя навигация временно скрывается при вводе.
- Убраны видимые слова «демо» и «демонстрация» из подписей Pages, профиля-примера, ошибок и аккаунта. Предупреждение о временном хранении вынесено в компактную строку верхней панели; на реальном серверном режиме её нет. Сообщения о недоступном ИИ/аккаунтах/оплате остаются точными. Pages по-прежнему не является backend и не хранит настоящие аккаунты.
- В выпуск включена ранее утверждённая поправка разных React-ключей quick-/mark- с существующим d5-регрессионным тестом.
