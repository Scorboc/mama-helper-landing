30. В ежедневном подборе источник возраста — `profile.ageMonths`, уже рассчитанный
    сервером по дате рождения и текущему календарному дню. Дата рождения модели
    не передаётся. Ноль полных месяцев — известный возраст, а не пустое значение.
    При неизвестном навыке выбирается допустимое занятие без требования этого навыка;
    условия бодрствования, интереса и остановки остаются в проверенных шагах каталога.
    Число вариантов берётся из запроса: три для дня, один для замены.
31. Проверка пустого дневника исправляет противоречащие ему утверждения о длительности,
    но сохраняет остальные части ответа, включая возраст активного ребёнка.
    Нет записей — нет данных. Это не ноль сна и не доказательство сбоя сохранения.
32. Предупреждение о подтягивании за руки отвечает на поставленный вопрос:
    обучение ходьбе и младенческое упражнение на удержание головы не смешиваются.
    Уточнения касаются навыка из вопроса; возраст не устанавливает норму или диагноз.
33. Родителю показываются обычные слова. Внутренние имена полей дневника и JSON
    остаются в технических данных, а не в тексте ответа.
34. Не ограничивать основания для обращения к врачу «лишь полным отсутствием интереса»
    и не объявлять поведение гарантированно безопасным по одному описанию.
    Наблюдения, устойчивое беспокойство и утрата навыков требуют соответствующего
    обсуждения, без ожидания абсолютного отсутствия навыка.
35. Нейтральный пример общения («Опишите, что делает другой ребёнок: …»)
    в ответе не означает смену профиля. Проверка входного вопроса о другом ребёнке
    остаётся строгой. Фильтр не должен стирать полезный пример и оставлять обрывок фразы.

## Основание и границы

Возраст и дневник проверены по фактическим запросам локального сервера и ответам
ProxyAPI. Для границ оценки развития проверены
[материалы CDC для 3 лет](https://www.cdc.gov/act-early/milestones/3-years.html):
рекомендация обсуждать беспокойство и утрату навыков; перечень навыков не заменяет
валидированный скрининг. Это не медицинская экспертиза всего чата.

## Что ИИ делает сейчас

- Чат: ответы, поддержка, анализ текущих записей сна и кормления, подготовка вопросов
  врачу и другие обращения из функций сайта через тот же чат.
- Ежедневный подбор: выбирает допустимые ID игр из проверенного возрастного каталога.
  Шаги игры приложение берёт из каталога.
- Замена: выбирает другую допустимую игру с учётом пояснения и причины отказа.
- «Помогло / не помогло»: отзыв сохраняется; отдельного вызова ИИ или автоматического
  переписывания инструкции эта кнопка не делает.
- Возрастные подсказки, текст push, карточка для мамы, графики и недельный отчёт:
  правила, шаблоны и расчёты, без самостоятельной генерации моделью.

Проверка закончена, когда известные дефекты закрыты указанными регрессиями.
Это не обещание отсутствия любой будущей ошибки модели.
