# Что передать в чат проекта «Поехали»

Код уже находится в GitHub. Чтобы включить настоящие аккаунты, скопируйте следующий запрос в чат **этого же проекта** на «Поехали»:

> Подключи сервер для подготовленной платформы «Мамин помощник». Сохрани дизайн и тексты. Используй backend/parent-app/index.py (handler index.handler) и requirements.txt. Создай таблицы PostgreSQL из backend/parent-app/schema.sql отдельной миграцией. Настрой DATABASE_URL, APP_DATA_KEY, APP_ORIGINS и CHEAPAI_API_KEY только в серверных секретах. APP_LOCAL в облаке не включать. Прочитай DEPLOYMENT.md и настрой доступ к функции, Cookie/Set-Cookie и CORS. Предпочтительно используй same-origin /api. Запиши реальный адрес функции в public/app-config.json. Сначала вызови action=health и action=config. Затем проверь регистрацию, вход, восстановление по коду, сохранение профиля, изоляцию двух аккаунтов, ответ чата с учётом возраста и удаление аккаунта. Настрой Web Push и ежедневный защищённый запуск reminders.handler по DEPLOYMENT.md. Не добавляй оплату, внешние медицинские ссылки, Вебвизор и трекеры в кабинет. После подключения проверь полный пользовательский путь на опубликованном сайте.

Пароли, ключи и строку подключения к базе не нужно присылать в GitHub или в этот документ. Они вводятся в защищённые настройки платформы.

После настройки можно отправлять тестировщику обычную ссылку сайта: главная → регистрация → сохранение кода восстановления → профиль → памятки и чат.

До настройки серверных функций работает `/demo`; форма регистрации прямо сообщает, что сервис аккаунтов ещё не включён. Она не создаёт фиктивный аккаунт в браузере.
