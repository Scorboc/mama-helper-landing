# Локальная проверка инструкций MAMA Helper

Установлены GEPA 0.1.4 и Promptfoo 0.124.1 в отдельном окружении.
Они не добавлены к зависимостям работающего приложения и не меняют его ответы.
Версии npm-пакетов закреплены в `pnpm-lock.yaml`, GEPA — в `requirements.txt`.

Черновик для владельца: `../../docs/ai/MAMA_SYSTEM_PROMPT_DRAFT.md`.
Инструкция для будущего улучшения: `OPTIMIZATION_BRIEF.md`.

## Что проверяет текущий запуск

`check_local.py` проверяет импорт GEPA, зависимости Python, версию Promptfoo,
чтение русского текста через локальный провайдер и сохранность исходного приложения.
Он возвращает текст файла, а не ответ ИИ. Успешный результат подтверждает установку,
но не качество медицинских ответов и не выполнение правил моделью.

В PowerShell из этой папки:

```powershell
& '.\.venv\Scripts\python.exe' '.\check_local.py'
```

Перед первым запуском на новой копии создайте исходный снимок:

```powershell
& '.\.venv\Scripts\python.exe' '.\preservation.py'
```

Повторная установка использует `install_local.py`, Python 3.12 и поставляемый
Codex Node 24 с pnpm 11.25.0. Скрипт использует их локальные пути; на другом
компьютере пути нужно адаптировать. Перед переустановкой создайте окружение `.venv`
из Python, затем запустите скрипт. Скрипт не вызывает модели.

## Данные и расходы

Обёртки исключают ключи приложения из окружения дочерних процессов.
Отключены телеметрия, проверка обновлений и удалённая генерация Promptfoo.
Для сохранения этих настроек запускайте проверки через `check_local.py`,
а не напрямую через глобальный CLI. Отчёты и локальная база Promptfoo лежат в
игнорируемой папке `output/`; не публикуйте их вместе с проектом.

Рабочие профили, медицинские сведения, переписка, база аккаунтов и ключи
не используются в конфигурации Promptfoo и не передаются моделям.
Проверка сохранности баз выполняется локально, сохраняет только количества строк
и контрольные суммы и не выгружает содержимое строк.

Для настоящей оценки потребуется отдельный адаптер к действующей модели,
синтетические сценарии и одобренный бюджет на ответы, оценивание и отражение GEPA.
Ключ берётся из окружения или существующего защищённого хранилища,
не из YAML и не из документа. Ограничение числа оценок не заменяет денежный лимит.
Не включайте облачную публикацию, автоматическую генерацию тестов или платный
запуск до отдельного разрешения владельца.

Нельзя передавать кандидат чат-промпта через текущий аргумент `system_prompt`
функции `chat_answer`: этот аргумент сейчас переключает запрос на режим «Мой день»
с JSON и отдельным учётом. Будущий адаптер должен явно различать эти режимы.
