# Локальный анализ «Помогло / не помогло»

Подключён `mamaLocal19` в существующем локальном n8n.

- Предложения: http://127.0.0.1:8791/#feedback-review
- Процесс: http://127.0.0.1:5678/workflow/mamaLocal19
- Сайт: http://127.0.0.1:5173/cabinet?tab=chat

Данные входа владельца n8n уже сохранены локально в
`private/n8n/owner-access.txt`. Не пересылайте и не публикуйте этот файл.

## Процесс

1. Родитель выбирает оценку под ответом и отправляет форму. Выбор кнопки без
   отправки формы ещё не является сохранённым отзывом. Комментарий необязателен.
2. Каждые 30 минут n8n обращается к защищённому локальному мосту. Тело запроса
   не содержит данных; существующий токен берётся из encrypted credentials.
3. Мост читает шифрованные отзывы. Один отзыв повторно не добавляется.
   Оригиналы `mh_feedback`, профили и диалоги не редактируются.
4. Локальные эвристики выделяют непонятный шаг, тон, повторение, устаревший
   дневник, возможную подмену возраста/профиля, техническую ошибку, служебные
   поля, небезопасный ответ и предложение функции.
5. Контекст читается только при сохранённом `consentContext=true`. Без него
   переписка не подгружается из других таблиц. Новый корпус переписок не создаётся:
   сохраняется только шифрованная ссылка на исходный отзыв.
6. ИИ получает закрытый набор категорий и числовые счётчики. Свободный текст,
   имя, дата рождения, заболевания, вопросы, ответы и пользовательские ID к
   провайдеру не передаются. Проверка схемы блокирует дополнительные поля до
   сетевого запроса. Отзыв не может стать инструкцией ИИ.
7. ИИ готовит до трёх предложений: гипотеза, проект правила, промпт разработчику,
   синтетический тест. Небезопасный ответ имеет P0 и обязательно включается.
   Остальные категории и локальные примеры остаются в панели, даже если не
   вошли в три предложения или анализ не удался.
8. Владелец открывает локальный пример, проверяет причину и выбирает «В план»
   либо «Отложить». Решение сохраняется, но правила и ответы не меняются.

«Помогло» не доказывает медицинскую достоверность. «Не помогло» — сигнал,
а не установленная ошибка. По счётчикам ИИ не подтверждает конкретную
медицинскую ошибку: нужен локальный просмотр и проверка официальных оснований.
Эвристики могут пропускать проблемы и ошибочно отмечать старые ответы, когда
возраст уже изменился. Не пересылайте локальные примеры внешним инструментам.

## Расходы и сбои

- Максимум один вызов в сутки по Москве; подлимит 1 ₽/день и 10 ₽/месяц входит
  в существующие общие бюджеты. Общие лимиты не повышены.
- Назначение в журнале расходов — `feedback-analysis`; ответы аккаунтов не списываются.
- Новые сигналы после дневного анализа ждут следующего дня. Положительная оценка
  без других сигналов не вызывает платный ИИ.
- При неизвестной стоимости резерв сохраняется. Автоматического повтора
  оплаченного вызова нет. Прерванный анализ требует локальной проверки владельца.
- HTTP-повтор n8n использует тот же `Idempotency-Key`; защищённый журнал
  не повторяет закончившееся или неопределённое действие.
- Error Trigger `mamaLocal18` записывает только ID процесса и исполнения.
  Telegram и внешние сообщения не подключены.

## Хранение

Результаты: `private/local-runtime/feedback-review/review.sqlite3`.
Исходные отзывы остаются в прежней шифрованной базе. Анализ добавлен в резервные
процессы и проверку восстановления. Удаление аккаунта удаляет его частные ссылки
на примеры; обезличенные предложения и учёт расходов остаются.

n8n и мост слушают только 127.0.0.1. Фоновый supervisor поддерживает службы после
закрытия чата Codex. Компьютер должен быть включён. После полного выключения
запустите `private/n8n/start_supervisor.py`; автозапуск после перезагрузки здесь
не настраивался и не проверялся. Не открывайте эти порты в интернет.

Ручной запуск: открыть процесс и нажать Execute Workflow. При отсутствии новых
сигналов `no-new-signals` — штатный успех. Пауза: Unpublish только `mamaLocal19`.
Это сохраняет отзывы, предложения и остальные процессы.

## Проверка и перенос

Использованы n8n 2.42.7, определения установленных узлов, штатные CLI
import/execute/publish, сверка сохранённых connections и credential по ID.
MCP n8n недоступен: `validate_workflow` MCP не выполнялся. Настоящее исполнение
n8n → ИИ → панель проверено на искусственных данных.

Генератор: `app/scripts/build-feedback-n8n.py`. Подключение:
`app/scripts/connect-feedback-n8n.py --prepare`, проверка, затем `--activate`.
После обновления backend: `--restart`. Скрипт останавливает только процессы
по проверенным путям и проверяет загрузку новой панели.

`mamaLocal19.json` содержит ссылку на credential, без секретного значения.
На другом компьютере потребуется локальный мост и его credential. Облачный n8n
не обращается к localhost вашего компьютера. Удалённый сервер не менялся.

Официальная документация:
[CLI n8n](https://docs.n8n.io/deploy/host-n8n/configure-n8n/use-the-command-line.md),
[хранение выполнений](https://docs.n8n.io/deploy/host-n8n/configure-n8n/basic-configuration/use-environment-variables/executions.md).
